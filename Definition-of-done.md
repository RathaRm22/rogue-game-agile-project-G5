# Definition of Done

This document outlines the criteria that must be met for any user story to be considered "done" in our project.

1. Code is completed and implements all acceptance criteria
2. Code has been peer-reviewed by at least one team member
3. Unit tests have been written and pass
4. Code has been integrated into the main branch without conflicts
5. Feature has been manually tested and works as expected
6. Documentation has been updated to reflect the changes
